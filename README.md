
# HSU 100 Learning Hub

Welcome to the HSU 100 Learning Hub!

A simple, responsive educational website designed to help students access Basic Life Support and Emergency Care study materials in one organised place.

## Features

- Modern and responsive website design
- Search for study materials
- Filter lecture notes and past papers
- Read PDF documents directly on the website
- Download PDF documents
- Mobile-friendly interface
- No installation required

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Browse the study materials.
5. Search, read and download the PDF documents.

## Important

Keep all PDF documents inside a folder named `pdfs`.

The PDF filenames must match the filenames listed in `script.js`.

## Project Purpose

The HSU 100 Learning Hub makes educational resources easier to organise, access and revise.

Happy learning!
